## Import Format

Импортёр принимает нормализованные JSON-выгрузки. Для официального источника в другом формате потребуется преобразование по его контракту. В рабочей конфигурации указывайте только подтверждённые источники. Для каждого источника проверьте права на автоматический импорт, охват, единицы измерения, актуальность и соответствие цен городу или точке. Ссылка на витрину предназначена для пользователя. Поле `feed` указывает на отдельную JSON-выгрузку, доступную по HTTPS или лежащую рядом с манифестом. Ниже пример формата, который сам по себе не подключает поставщика данных.

```json
[
  {
    "chain": "magnit",
    "city": "domodedovo",
    "store_key": "city",
    "source_url": "https://magnit.ru/catalog",
    "feed": "magnit-domodedovo.json",
    "partial": true
  }
]
```

Идентификаторы сетей и городов определены в `backend/app/catalog_data.py`. Для цены конкретной точки укажите её идентификатор в `store_key` и понятный адрес в `store_name`. У «Красное&Белое» точка обязательна.

Формат файла выгрузки ниже. Тестовое название, цена и время приведены для иллюстрации структуры.

```json
{
  "chain": "magnit",
  "city": "domodedovo",
  "store_key": "city",
  "observed_at": "2026-11-08T18:00:00+03:00",
  "products": [
    {
      "id": "stable-id-from-source",
      "name": "Пример товара",
      "category": "Пример категории",
      "unit": "шт.",
      "price_kopecks": 10000
    }
  ]
}
```

`observed_at` — время, когда источник показал эти цены. Сохраняйте стабильные идентификаторы товаров между обновлениями. Для товара можно добавить официальный `source_url`. Фоновый процесс импортирует при запуске и затем каждый час. После ошибки предыдущие цены сохраняются с отметкой об устаревании. Эта отметка также появляется, если выгрузке более 48 часов.

## Release Check

После настройки выгрузок выполните проверку. Команда завершается с ошибкой, если отсутствует свежий успешный импорт хотя бы для одной пары «сеть и город».

```sh
docker compose stop worker
docker compose run --rm --no-deps worker python -m app.import_catalogs
docker compose up -d worker
```

На приёмке сверяйте цены с официальным источником для выбранного города или магазина. Для сетей с частичным каталогом сверяйте покрытие с согласованной выгрузкой.
